# Where to look for stories

Edit freely: add or remove sources at any time. Search across ALL groups every run, not just the first.
Rules: no more than 2 stories from the same outlet per edition. Prefer free-to-read pages. If a page is blocked (PubMed, PMC, paywalls), find the same finding on the institution's or journal's own page.
